# HOLLOW SPIRE CARTOGRAPHY RULES v1.0

1. Maps are usually correct. Interpretations are usually wrong.
2. Explorer maps only contain information personally obtained by the explorer.
3. Explorer maps are records of experience, not records of reality.
4. Before information appears on an explorer map, answer: **How does this explorer know this?**
5. Explorer maps should not automatically inherit DM terminology.
6. Every explorer has Reach: some areas are fully explored, partially explored, abandoned, or never reached.
