# The Hollow Spire

A dark mythic fantasy megadungeon campaign setting.

## Book One: The Light Below
Covers Floors 1–10 of the Hollow Spire, including the Black Cells, Floodwater Passages, Outpost Emberlight, the Long Dark, Lantern Village, the Veiled Warrens, and the Moon Lantern Sanctuary.

## Core Themes
- Hope in darkness
- Exploration as service
- Legacy over wealth
- Truth, memory, and recurrence
- Civilization surviving through mutual aid

## Project Structure
- `Homebrewery/` — Homebrewery source files and layout notes
- `Maps/` — DM, player, and updated map versions
- `Art/` — NPC, settlement, relic, and landmark images
- `Handouts/` — printable player-facing documents
- `Bestiary/` — creature entries and encounter references
- `NPCs/` — major NPC dossiers
- `Timeline/` — campaign and mystery chronology
- `Mysteries/` — hidden lore, long-term clues, and GM-only secrets
- `Archive/` — deprecated drafts and old versions
