# Registry Frameworks v1.0 — Prompt Trace

## Origin

This package was created during Floor 001 development after the following needs were identified:

1. Explorer Map Contradictions v1.0
2. Discovery Registry v1.0
3. Encounter Registry v1.0
4. Loot Registry v1.0

During discussion, the user clarified that Discovery needs a checklist with:

- Zone.
- Point value.
- DM tally section.
- Hidden threshold compatibility.

The user also identified a broader need:

- A list of what players track regularly.
- A list of what DMs track regularly.
- Inclusion of the 100 Warden Questions that players answer unknowingly.

## Frameworks Completed In This Package

This package completes the three broader frameworks:

1. Discovery Registry Framework v1.0
2. Campaign Tracking Framework v1.0
3. Warden Question Framework v1.0

## Remaining Registry Work

The following still require full individual registry documents:

1. Explorer_Map_Contradictions_v1.0
2. Encounter_Registry_v1.0
3. Loot_Registry_v1.0

Discovery Registry Framework v1.0 is complete, but floor-specific Discovery Registries should be created per floor.

## Key Locks

- Discovery is checklist-driven and DM-facing.
- Discovery entries include zone and point value.
- Discovery checklists include tally sections.
- Players track maps, contracts, Codex, Lantern Stability, supplies, companions, settlement notes, and journals.
- DMs track Discovery, thresholds, encounter state, hunts, Codex progress, lantern network, settlements, Silent Jailer, escaped entity, Seven Seals, Warden Questions, and Recurrence clues.
- Warden Questions are hidden and answered through play.
- The 100 Warden Questions are distributed across the Seven Seal virtues.
