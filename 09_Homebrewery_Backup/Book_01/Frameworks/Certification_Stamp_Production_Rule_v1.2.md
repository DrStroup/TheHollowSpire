# Certification Stamp Production Rule v1.2

Status: LOCKED

The certification stamp should resemble a clerk's rubber stamp impression,
not a seal, emblem, badge, medallion, coin, logo, crest, or wax seal.

Symbol Hierarchy:
- Lantern = Primary
- Text Ring = Secondary
- All other elements = Optional

Transparency Rule:
The stamp must be rendered as isolated black ink artwork suitable for extraction onto an alpha-transparent PNG.

Ink Rule:
No white fill areas.
All visible elements are created by ink.

Visual Goal:
Guild Reviewed
Guild Verified
Contract Legitimate
