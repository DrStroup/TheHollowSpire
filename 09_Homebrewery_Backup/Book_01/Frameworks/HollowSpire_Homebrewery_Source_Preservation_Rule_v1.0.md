# Hollow Spire Homebrewery Source Preservation Rule v1.0

## Status
LOCKED for all publication pushes.

## Rule
Every publication ZIP/push must include a full text copy of the current Homebrewery source.

## Required File
09_Homebrewery/Book_01/Source/Book_01_Homebrewery_Source_vX.X.txt

## Required Alongside It
Each publication push must also include:

- an export changelog
- any new or revised framework files
- audit notes when applicable

## Purpose
This protects the project if Homebrewery corrupts content, GitHub history becomes confusing, or future chats need a complete source snapshot.
