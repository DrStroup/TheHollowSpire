# Chapter 00 Redesign Audit Checklist v2.0

A Chapter 0 page is not complete until it passes all relevant checks.

## Universal Checks
- Running header follows recto/verso standard.
- No Homebrewery footer filigree.
- No visible page number unless intentionally restored later.
- Headings are black.
- No technical 0.x section numbering.
- Page has at least one intentional visual anchor.
- Sidebar content is replaced by or planned for a diegetic artifact where possible.
- Text does not appear as a plain block with empty lower-page space.

## Page 9 Specific Checks
- Artwork feels integrated, not appended.
- Explorer Note is treated as an in-world object or has a clear placeholder for that asset.
- Title, header, body text, note, and artwork form one composition.
- Visual balance is closer to designed spread than manuscript page.

## Chapter-Level Checks
- Chapter 0 compresses cleanly without feeling cramped.
- Each page establishes a repeatable design pattern for future chapters.
- Artifact types are distinguishable from one another.
- Art direction supports the Explorer Guild identity.
