# Hollow Spire Publication HeaderFooter Framework v2.0

STATUS: LOCKED

Purpose:
Establish header, footer, page numbering, and crest behavior for all Hollow Spire publication layouts.

--------------------------------------------------
STANDARD MANUSCRIPT PAGE
--------------------------------------------------

Requirements:

Header: YES
Footer: YES
Page Number: YES
Guild Crest: YES

Examples:
- Explorer Guild
- Discovery
- Contracts
- Exploration & Danger

Layout:

HEADER

MANUSCRIPT CONTENT

PAGE NUMBER
GUILD CREST

--------------------------------------------------
TOP ART PAGE
--------------------------------------------------

Definition:
Artwork occupies the upper portion of the page.

Requirements:

Header: NO
Footer: YES
Page Number: YES
Guild Crest: YES

Reason:
The artwork functions as the visual header.

Layout:

ARTWORK

MANUSCRIPT CONTENT

PAGE NUMBER
GUILD CREST

--------------------------------------------------
BOTTOM ART PAGE
--------------------------------------------------

Definition:
Artwork occupies the lower portion of the page.

Requirements:

Header: YES
Footer: NO
Page Number: NO
Guild Crest: NO

Reason:
The artwork functions as the visual footer.

Layout:

HEADER

MANUSCRIPT CONTENT

ARTWORK

Current Example:
Chapter_00_Art_01_The_First_Descent_v2
Page 09

--------------------------------------------------
FULL PAGE SPLASH
--------------------------------------------------

Requirements:

Header: NO
Footer: NO
Page Number: NO
Guild Crest: NO

Examples:
- Chapter Splash Pages
- Region Splash Pages

--------------------------------------------------
FULL BLEED PAGE
--------------------------------------------------

Requirements:

Header: NO
Footer: NO
Page Number: NO
Guild Crest: NO

Examples:
- Cover Pages
- Full Bleed Illustrations

--------------------------------------------------
SIDE ART PAGE
--------------------------------------------------

Requirements:

Header: YES
Footer: YES
Page Number: YES
Guild Crest: YES

Reason:
Side art does not replace header or footer regions.

--------------------------------------------------
PUBLICATION RULE
--------------------------------------------------

When artwork occupies a header region, the header is removed.

When artwork occupies a footer region, the footer is removed.

Artwork becomes part of the page structure rather than competing with page furniture.

This framework supersedes previous header/footer guidance.
