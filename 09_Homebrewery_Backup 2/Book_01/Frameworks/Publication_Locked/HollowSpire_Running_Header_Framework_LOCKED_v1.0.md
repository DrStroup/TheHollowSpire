# Hollow Spire Running Header Framework v1.0 — LOCKED

## Rule
Running headers are manually placed per publication page. Do not rely on `nth-child` or automatic page parity detection in Homebrewery.

## Verso / Even Pages
- Header position: left aligned.
- Header text: `Book I — The Blackwater Warrens`.

## Recto / Odd Pages
- Header position: right aligned.
- Header text: `Chapter 0 — The Explorer Guild Primer`.

## Style
- Black only.
- Small caps / uppercase presentation.
- No page numbers.
- No default Homebrewery footer filigree.
- Inline positioning may be used when Homebrewery drops header classes into normal document flow.
