# Framework Status Register v1.0

## Status Definitions

- Publication_Locked: authoritative publication standards; do not modify without a versioned update.
- Active: current working frameworks still allowed to evolve.
- Superseded: replaced by newer frameworks; retained for history but should not be referenced as current rules.
- Archive: historical implementation notes, experiments, and migration references.
- Compilations: consolidated overview documents for quick reference.

## Current Authoritative Guidance

Use `Publication_Locked/` first for production layout and workflow rules.

Use `Active/` for current systems still being developed, including contracts, heraldry, diegetic artifacts, and the simplified certification stamp.

Do not use `Superseded/` for new work unless auditing project history.
