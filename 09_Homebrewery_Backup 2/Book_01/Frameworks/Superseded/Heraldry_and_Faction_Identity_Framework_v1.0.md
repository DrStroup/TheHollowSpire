# Heraldry & Faction Identity Standard v1.0

Core Rule:
A crest should only appear when the document has a reason to display one.

Valid Uses:
- Explorer Guild documents: guild manuals, contracts, reports, notices.
- Pilgrim documents: pilgrim records, sermons, religious notices.
- Settlement documents: village notices, local contracts, records.
- Unknown/recovered journals: often no crest at all.

Design Principles:
- Heraldry communicates authorship.
- Unknown documents should not be artificially branded.
- If a crest is used, it must be a canon faction crest.
- Never use generic fantasy symbols as substitutes.

Future Faction Package:
Each major faction receives:
- Crest
- Seal
- Document style
- Color palette
- Border motif
