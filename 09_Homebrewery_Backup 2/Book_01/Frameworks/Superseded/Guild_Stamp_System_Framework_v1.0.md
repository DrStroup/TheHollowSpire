# Guild Stamp System Framework v1.0

## Purpose

Explorer Guild stamps communicate administrative review and contract risk.

These are not faction crests.

## Canon Stamp Colors

Green
- Low Risk
- Routine
- Beginner Friendly

Blue
- Moderate Difficulty
- Verified Exploration Work

Red
- High Risk
- Dangerous
- Significant Threat

Purple
- Extreme Risk
- Restricted Access
- Advanced Explorers

## Administrative Meaning

A stamp communicates:

- Reviewed
- Risk Assessed
- Reward Verified
- Contract Legitimate

## Design Rule

All stamp variants belong to the same family:

- Same lantern symbol
- Same overall structure
- Different ink colors communicate category
