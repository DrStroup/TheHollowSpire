# Certification Stamp Generation Rule v1.0

## Locked Rule

The Explorer Guild Certification Stamp is a reusable production asset.

Generate:

- One stamp
- One approval mark
- Transparent background preferred
- Distressed ink style
- Lantern motif
- Explorer Guild Certified wording

Do NOT generate:

- Catalog sheets
- Multiple stamp variants
- Presentation boards
- Explanatory pages
- Administrative showcases

## Purpose

The certification stamp is intended to be reused across many future artifacts.
