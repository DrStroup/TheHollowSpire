# Hollow Spire Publication Art Frameworks v1.0

STATUS: LOCKED

Purpose:
Establish standard art-generation templates for all future Hollow Spire publication assets.

Core Principle:
Layout is determined BEFORE art generation.
Art is generated to fit a predefined Homebrewery template.

--------------------------------------------------
Generation Requirements
--------------------------------------------------

Every art request must specify:

1. Asset Name
2. Homebrewery Template
3. Intended Page
4. Aspect Ratio
5. Safe Zones
6. Canon Requirements
7. Visual Goal

Example:

Asset:
Chapter_00_Art_01_The_First_Descent

Template:
HB_Panorama_Bottom_v1

Aspect:
21:9

Safe Zones:
Top 20%
Bottom 10%
Sides 5%

Visual Goal:
Explorers overlooking Emberlight Village within a vast underground cavern.

--------------------------------------------------
Publication Rule
--------------------------------------------------

Do not generate Hollow Spire artwork until the intended placement template has been selected and documented.
