# Image Generation Review Rule v1.0

## Locked Rule

Each time a new image asset is generated for the first time, it must be reviewed before it is accepted, revised, placed into layout, or used as the basis for additional dependent assets.

## Required First-Generation Review

Every first-generation image review must evaluate:

- Correct asset purpose
- Correct owning faction or lack of faction
- Correct crest/seal use
- No generic non-canon heraldry
- Readability at intended Homebrewery placement size
- Fit with Hollow Spire tone
- Print usefulness
- Whether the image is a prototype, revision candidate, or locked asset

## Review Outcomes

Allowed statuses:

- Prototype Approved
- Revision Required
- Rejected
- Locked for Layout
- Retired

## Workflow Requirement

No asset enters the Artifact Library Registry as `Locked` until it has received a review pass.
