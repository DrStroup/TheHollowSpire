# Certification Stamp Production Rule v1.1

## Production Requirements

The production certification stamp must be:

- Transparent PNG
- Single stamp asset
- Black ink (Standard tier)
- Reusable across artifacts
- Flat ink impression

## Visual Direction

Prioritize:

- Bureaucratic authenticity
- Ink transfer imperfections
- Administrative tool appearance
- Distressed stamp edges

Avoid:

- Raised emblems
- Medallion appearance
- Badge-like presentation
- Crest-like complexity

## Symbol Hierarchy

Lantern = Primary symbol

Compass/starburst elements may be present but must remain secondary.
