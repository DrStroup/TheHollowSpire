# Chapter 00 Redesign Page Map v2.0

## Goal
Turn Chapter 0 from a text-forward primer into a compact, art-rich publication chapter that establishes the design language for Book I.

## Current State
- Pages 1-8: front matter and splash pages
- Page 9: chapter opener, mostly functional but still improvable
- Pages 10-16: manuscript pages with limited visual identity

## Target Structure

### Page 9 — Chapter Opener
Content:
- Chapter 0: The Explorer Guild Primer
- Welcome to the Hollow Spire
- Opening Explorer Note artifact
- Bottom environmental artwork

Design Goal:
A single integrated composition, not a top text / bottom art split.

Potential Improvements:
- Convert Explorer Note #1 from sidebar to Explorer Field Journal artifact.
- Allow the art to climb farther into the page with a soft mask.
- Add small Guild seal or lantern motif near the chapter title.

### Page 10 — Guild Identity Page
Content:
- The Explorer Guild
- Travel Within the Spire
- Discovery, if space allows or as a clean continuation onto Page 11

Visual Anchor:
- Guild Training Manual artifact explaining the Spire transit law.
- Guild seal watermark.
- Discovery Report mini-form or annotated sketch if Discovery remains on this page.

### Page 11 — Discovery and Contracts Page
Content:
- Discovery
- Contracts
- Example Contract

Visual Anchor:
- Contract posting asset replacing the current contract sidebar.
- Optional small notice-board pin/wax seal.

### Page 12 — Danger and Wonder Page
Content:
- Exploration & Danger
- Horror & Wonder

Visual Anchor:
- Danger marker iconography.
- Recovered Journal artifact.
- Crystal cavern environmental sketch.

### Page 13 — Closing Ethos Page
Content:
- Leave the World Better Than You Found It
- Beginning the Journey

Visual Anchor:
- Route map fragment.
- Traditional Guild Farewell artifact.
- Lantern icon or final path motif.

## Stretch Goal
If compression feels too dense, allow Chapter 0 to become five content pages instead of four. Publication quality is more important than minimum page count.
