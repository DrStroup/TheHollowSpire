# Artifact Library Registry Rule v1.0

## Locked Rule

The Artifact Library Registry must be updated whenever an artifact asset is:

- Planned
- Generated
- Reviewed
- Revised
- Placed
- Replaced
- Locked
- Retired

## Registry Requirements

Each entry must track:

- Asset ID
- Asset name
- Chapter
- Target page
- Owning faction
- Crest or seal usage
- Current version
- Current status
- File path
- Notes
