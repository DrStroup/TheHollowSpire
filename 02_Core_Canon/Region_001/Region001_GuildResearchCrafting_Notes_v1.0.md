# Region 001 Guild Research & Crafting Notes v1.0

## Early Region 001 Use

The first use of this system should be simple and clear.

Example:

The party reaches Emberlight with enough Discovery for the Guild Alchemist to trust them with basic preparation work.

If they have gathered the correct materials, the alchemist can create a small number of special Guild potions.

## Early Candidate Recipe

### Lesser Lantern Draught

Availability:
Discovery Threshold 50.

Requires:
- Iron Rat Whiskers.
- Glowcap Mushrooms.
- Treated lantern oil.

Specialist:
Guild Alchemist.

Reward:
A small number of Guild-only exploration potions.

Purpose:
Teach that materials are useful, but only in specific contexts.

## Important Rule

Do not let Emberlight become a generic vendor economy.

The alchemist should feel like a researcher solving local problems with local materials.
