# Explorer Map Contradictions v1.0

## First Appearance
Zone 01 — Black Cells  
Area A3 — Explorer's Cell

## Handout
Explorer Map #17

## Design Rule
The first contradiction should not scream time travel, Recurrence, or impossible reality.

It should seem like an old or inaccurate explorer map.

## Valid Contradictions
- A corridor is drawn where a wall currently exists.
- A room is marked that the players cannot find.
- A door is shown in a different position.
- A collapsed passage appears open on the map.
- A minor label disagrees with the current surroundings.

## Invalid Contradictions
- Map includes the party's names.
- Map predicts future events.
- Map directly references rebirth.
- Map confirms prior descents.
- Map states that the party has been here before.

## Purpose
Plant long-term mystery while preserving Recurrence as late-game canon.
