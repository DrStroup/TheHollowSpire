# Export Rule v0.03

Every major work process must end with:

1. GitHub structure check.
2. Work package completion.
3. ZIP export mirroring the locked GitHub structure.
4. User upload/commit to GitHub.
5. Homebrewery draft/update for the completed section.
6. Preservation ZIP including markdown, assets, registries, and Homebrewery draft.

No major section is complete until it exists in:
- Working canon
- GitHub-mirrored ZIP
- Homebrewery draft
