# Export Rule v1.0 Package

This package locks the Hollow Spire asset export workflow.

## Locked Workflow

Every asset lock must produce a Git-ready export package with:

1. Canon File
2. Art Direction File
3. Homebrewery Asset Files
4. Publication Placement File
5. Export Package
6. Prompt Trace

## Purpose

This workflow prevents orphan exports and ensures future asset locks can be pushed directly into the repository structure.
