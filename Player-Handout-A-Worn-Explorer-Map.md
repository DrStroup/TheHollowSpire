# Hollow Spire Homebrewery Style Guide

## Formatting Conventions

- Use `#` for book/chapter title pages.
- Use `##` for major sections.
- Use `###` for encounter areas or keyed map areas.
- Use blockquotes for read-aloud text.
- Use bold labels for quick GM reference.
- Use `\page` for page breaks.

## Asset Placeholders

Use stable IDs for art and maps until final URLs are available.

Examples:

```html
<img src='ART-001-Lantern-Village-Arrival.png' style='width:100%' />
```

```text
[MAP-001 Black Cells DM Version]
[MAP-002 Black Cells Player Version]
[MAP-003 Black Cells Moon Lantern Update]
```
