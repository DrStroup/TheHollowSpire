# Chapter 0 Asset Generation Checklist v1.1

## Phase 0: Canon Review

- [ ] Who created this document?
- [ ] Why was it created?
- [ ] Is it public, private, official, personal, or recovered?
- [ ] Does it belong to a known faction?
- [ ] If yes, which canon crest or seal should appear?
- [ ] If no, no crest should be present.
- [ ] Should it be clean, damaged, worn, or partially illegible?
- [ ] What page does it support?

## Phase 1: First-Generation Review

- [ ] Review image immediately after first generation
- [ ] Confirm no generic non-canon symbols
- [ ] Confirm intended document type is readable
- [ ] Confirm artifact works at intended placement size
- [ ] Confirm it feels used and diegetic
- [ ] Assign status: Prototype Approved / Revision Required / Rejected / Locked
