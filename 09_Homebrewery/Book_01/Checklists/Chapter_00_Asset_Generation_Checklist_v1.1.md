# Chapter 00 Asset Generation Checklist v1.1

## Phase 0 — Canon Review
Before generating an asset, answer these questions:

- [ ] Who created this document?
- [ ] Why was it created?
- [ ] Is it public, private, official, recovered, copied, or archival?
- [ ] Should it survive in good condition?
- [ ] Should it be damaged, stained, folded, burned, torn, or water-warped?
- [ ] Does it belong to a known faction, settlement, guild, order, or cult?
- [ ] If yes, which canon crest/seal/stamp should appear?
- [ ] If no, confirm that no crest should appear.
- [ ] Does the asset add immersion beyond a normal sidebar?
- [ ] Has the Artifact Library Registry been updated before generation?

## Phase 1 — Style Lock
- [ ] Confirm asset purpose.
- [ ] Confirm document owner/source.
- [ ] Decide whether crest/seal/stamp is required.
- [ ] Select parchment, notebook, contract, journal, map, or notice-board style.
- [ ] Confirm orientation: portrait, landscape, square, strip, or irregular fragment.
- [ ] Confirm Homebrewery placement target and approximate dimensions.
- [ ] Confirm final readable text.
- [ ] Confirm whether text should be embedded in the image or recreated as HTML overlay.
