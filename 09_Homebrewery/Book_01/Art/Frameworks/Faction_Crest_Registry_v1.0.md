# Faction Crest Registry v1.0

## Purpose
Tracks approved canon crests, seals, stamps, and heraldic identifiers for use in Hollow Spire publication assets.

## Rule
Only registered canon heraldry may appear in final publication assets.

---

## Registered Heraldry

### Explorer Guild
- Status: APPROVED / ACTIVE
- Primary Crest: Explorer Guild lantern, compass, and open book crest
- Current Asset Reference: `09_Homebrewery/Book_01/Art/Logos/` or current repository crest location
- Usage: official Guild documents, Guild contracts, route maps, training documents, discovery reports, field reports, Guild-certified copies
- Notes: Do not use as a universal decoration. Use only when ownership or certification is Guild-related.

## Registry Maintenance
When a new crest is created:
1. Add faction name.
2. Add status.
3. Add source asset path.
4. Add approved usage cases.
5. Add forbidden usage cases if needed.
6. Update Artifact Library Registry entries that use it.
