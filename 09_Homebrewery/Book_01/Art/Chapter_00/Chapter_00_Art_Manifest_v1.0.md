- no footer on full-page art/front-matter/splash pages unless specifically approved

Suggested visible format:

`[small crest]  9`

or

`[small crest centered above page number]`

Final implementation should be tested in Homebrewery render before lock.

## Pages Excluded from Footer

Do not show footer/page numbers on:

- cover page
- blank reverse
- title page
- dedication page
- oath page
- credits page
- contents placeholder page
- Chapter 0 splash page

Begin visible page numbering on the first manuscript page after the Chapter 0 splash unless a future global pagination framework overrides this.

---

## Art Style Guidance

All Chapter 0 illustrations should feel consistent with the existing Hollow Spire visual identity:

- subterranean fantasy
- lantern-lit atmosphere
- explorer tools and guild identity
- gold, amber, parchment, black, deep blue, and muted earth tones
- wonder mixed with danger
- practical exploration rather than heroic posing
- no overt reference to protected fantasy IP or proprietary monsters
- no modern items
- no visible text that needs to be readable unless created intentionally in layout

---

## Audit Requirements Before Lock

Each generated illustration must pass:

- correct filename
- correct folder location
- no obvious visual artifacts
- no unwanted text or unreadable fake text in focal areas
- consistent tone with Hollow Spire
- no proprietary/trademarked names or protected creatures
- usable at Homebrewery page scale
- does not interfere with manuscript readability
- visually supports the assigned section
