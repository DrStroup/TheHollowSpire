# Guild Stamp Player Communication Rule v1.1

## Locked Rule

Visual systems may teach players world rules before text does.

The Guild Stamp System is a formal player-facing visual language.

## Stamp Reading Priority

1. Color communicates risk category.
2. Stamp presence communicates Guild review.
3. Contract text communicates specifics.

## Default

Black is the standard Guild certified posting color.

Colored stamps should draw attention to unusual risk, difficulty, restriction, or urgency.
