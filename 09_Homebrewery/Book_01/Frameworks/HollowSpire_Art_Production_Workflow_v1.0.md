# Art Production Workflow Update v1.0

STATUS: LOCKED

New Rule:

Layout First.
Art Second.

Workflow:

1. Identify manuscript page.
2. Determine final art placement.
3. Select Homebrewery template.
4. Lock aspect ratio.
5. Lock safe zones.
6. Generate artwork.
7. Integrate into Homebrewery.
8. Audit PDF render.
9. Lock asset.

Reason:

Art_01 demonstrated that high-quality artwork can still create publication issues if placement requirements are not defined before generation.

Future artwork should be treated as publication assets, not standalone illustrations.
