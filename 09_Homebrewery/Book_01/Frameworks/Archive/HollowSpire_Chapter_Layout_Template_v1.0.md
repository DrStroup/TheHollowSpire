# Hollow Spire Chapter Layout Template v1.0

## Status
LOCKED as a guiding framework.

## Standard Chapter Flow
1. Chapter splash page
2. Chapter opening page or opening spread
3. Compressed topic sections with clean breaks
4. Artifacts, spot art, maps, sketches, and motifs distributed across content pages
5. Closing section with transition into the next gameplay or narrative phase

## Content Page Expectation
Each page should combine readable text with one or more visual anchors.

## Chapter 0 Use
Chapter 0 should be redesigned into a shorter, art-rich Explorer Guild primer rather than a sequence of one-topic text-only pages.
