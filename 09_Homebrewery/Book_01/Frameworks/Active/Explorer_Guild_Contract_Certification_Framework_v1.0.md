# Explorer Guild Contract Certification Framework v1.0

## Status
Active

## Locked Workflow

Explorer Guild contract certification follows this sequence:

1. Contract written.
2. Contract filed.
3. Contract signed by clerk.
4. Contract stamped.
5. Contract posted.

## Stamp Placement Rules

The Explorer Guild certification stamp may overlap:

- Signature flourish or tail
- Ledger reference
- Filing marks
- Routing marks
- Posting instructions

The stamp must not obscure:

- Signatory name
- Contract objective
- Rewards
- Location
- Difficulty
- Primary player-facing text
