# Heraldry Generation Restriction v1.0

Status: Active

No image generation may invent faction heraldry, guild crests, seals, banners, insignia, or logos.

All heraldic imagery must originate from:
1. An approved Hollow Spire asset.
2. A locked faction registry entry.
3. A previously approved crest library asset.

If none exists, leave the space blank or typographic.
