## Production Note
Assets should be created as reusable transparent PNGs sized for Homebrewery placement.
Text-heavy artifacts may need either:
1. text baked into the art asset, or
2. blank parchment asset with live HTML text overlaid.

Preferred workflow: create blank reusable artifact PNGs first, then overlay live Homebrewery text for editability.
