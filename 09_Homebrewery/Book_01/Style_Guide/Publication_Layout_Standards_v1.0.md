
# Book 01 Publication Layout Standards v1.0

LOCKED DECISIONS

PAGE NUMBERING

Front Matter:
- Cover Page
- Title Page
- Dedication
- Explorer Guild Oath
- Credits
- Table of Contents

No visible page numbers.

Main Book:
Visible page numbering begins on Chapter 0.

Chapter 0 Page Number:
1

FOOTER STANDARD

All numbered pages contain:

Centered Page Number

Explorer Guild Crest directly beneath the page number.

Example:

      24
 [Explorer Guild Crest]

Exceptions:
- Cover Page
- Chapter Splash Pages

No footer.
No page numbers.

HEADER STANDARD

Interior Pages Only

Left Header:
The Hollow Spire

Right Header:
Book I — The Blackwater Warrens

Purpose:
Create the appearance of an Explorer Guild publication.

BRANDING GOAL

The publication should feel like an Explorer Guild archive and field guide rather than a traditional adventure module.
