# Asset Lock Export Checklist v1.0

Use this checklist before every Hollow Spire asset export.

## Required

- Canon file created or updated in `02_Core_Canon/` when canon is established.
- Art direction file created or updated in `08_Art_Registry/` when visual rules are established.
- Homebrewery asset files placed in `09_Homebrewery/Book_01/Assets/Asset_xxx/`.
- Publication placement file placed under the relevant page folder.
- Export package placed under `12_Exports/`.
- Prompt trace included.
- Changelog included.
- README included.

## Quality Bar

The export should be directly pushable to GitHub without needing to manually sort files.

## Failure Condition

If files are placed only at the root of a zip, the package is incomplete.
