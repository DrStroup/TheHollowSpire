# Encounter Framework v0.02

Every encounter packet must contain:

- Encounter ID
- Encounter Name
- Purpose
- Location
- Trigger
- Read-Aloud Text
- Participants
- Terrain Features
- Objectives
- Discovery Hooks
- Recovery Opportunities
- NPC Integration
- Warden Ledger Hooks
- Explorer Notes
- Scaling Notes
- Aftermath
- DM Notes

## Required Audits

Before an encounter may be locked:

- Mechanical Audit
- Reward Audit
- Recovery Audit
- Discovery Asset Audit
- Discovery Archive Registration Audit

## Mechanical Audit Rule

Every referenced mechanic must be:
- Pathfinder 1e defined
- Hollow Spire defined
- Explicitly narrative

## Reward Audit Rule

Only allowed rewards:
- Discovery Credit
- Recovery Cache
